# Security Policy

## Supported versions

This fork has no versioned releases. Only the latest commit on the `main` branch receives security fixes. Vercel deploys that commit to [github-readme-streak-stats.nixrajput.com](https://github-readme-streak-stats.nixrajput.com).

| Version                                       | Supported |
| --------------------------------------------- | --------- |
| Latest commit on `main` (deployed)            | Yes       |
| Older commits and self-hosted deploys of them | No        |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

### Option 1 - GitHub private advisory (preferred)

Use GitHub's private vulnerability reporting:

[https://github.com/nixrajput/github-readme-streak-stats/security/advisories/new](https://github.com/nixrajput/github-readme-streak-stats/security/advisories/new)

### Option 2 - Email

Send a description of the vulnerability to **<nkr.nikhil.nkr@gmail.com>**. Include:

- A clear description of the issue and its potential impact.
- Steps to reproduce or a proof-of-concept.
- Any suggested remediation if you have one.

## Response expectations

| Milestone          | Target                           |
| ------------------ | -------------------------------- |
| Acknowledgement    | Within 72 hours                  |
| Initial assessment | Within 7 days                    |
| Fix or mitigation  | Within 30 days for high-severity |

You will be credited in the pull request that fixes the issue unless you prefer to remain anonymous. Thank you for helping keep this project secure.
